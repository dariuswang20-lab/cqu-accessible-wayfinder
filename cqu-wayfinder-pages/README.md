# 知路 · 重庆大学无障碍寻路交互原型

这是《人机交互与人工智能》课程的静态网站原型，重点演示重庆大学 B 校园第二综合楼的互动寻路场景，并展示 A、B、C 校园图片。

## 发布到 GitHub Pages

本仓库根目录即发布目录。在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，将分支设为 **main**、目录设为 **/(root)**，保存后访问 `https://<用户名>.github.io/cqu-wayfinder/`。

网站使用相对路径引用本地 CSS、JavaScript 和校园图片，无运行时外部资源依赖。GitHub Pages 的发布成功不等于中国大陆所有网络均可稳定访问，应对正式网址做大陆多地区、不同运营商的 HTTP 检测。

## 原型范围

用户可以切换校园、选择起终点和通行偏好、模拟电梯停用与通道封闭、比较路线，并完成匿名用户测试和 CSV 导出。楼层图、路线距离与设施状态是课程研究用模拟数据，不能用于真实导航或疏散。校园照片来源和说明见网站页面。
